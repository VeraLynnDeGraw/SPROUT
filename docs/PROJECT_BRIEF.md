# SPROUT Project Brief

## Purpose
Help users track small goals and record progress.

## First release
- Add a growth item.
- View existing items.
- Record a progress note.
- Edit and remove items.
- Preserve data locally.
- Export data as JSON.

## Constraints
- No paid services.
- No mandatory account or API.
- Keep the code small and readable.
- Explain and verify each milestone.

## Acceptance criteria
- Core actions work.
- Saved data survives a page refresh.
- Invalid input is handled.
- Data can be exported.
- Build and test results are recorded honestly.
