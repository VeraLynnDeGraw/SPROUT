# SPROUT Project Brief

## Purpose

Help users track small milestones and see their progress represented by a growing pixel-art tree.

SPROUT is also a reusable starting point for people who want to experiment, learn, and create their own version.

## Current scope

- Add milestones.
- View existing milestones.
- Edit and remove milestones.
- Preserve milestone data in browser local storage.
- Display progress through a pixel-art tree.
- Run locally without a required account, paid service, or external API.
- Allow users to customize their own template-generated copies.

## Constraints

- No paid services.
- No mandatory account or API.
- Keep the code small and readable.
- Preserve user control over locally stored data.
- Explain and verify each milestone.
- Document limitations honestly.
- Keep contribution expectations understandable.

## Acceptance criteria

- Core milestone actions work.
- Saved data survives a page refresh.
- Invalid input is handled appropriately.
- The tree reflects milestone progress.
- The application runs locally using the documented instructions.
- Changes are tested and their results are recorded honestly.

## Future ideas

These are possibilities, not claims about current functionality:

- Export and import milestone data as JSON.
- More tree designs and customization options.
- Additional accessibility improvements.
- Community-contributed themes and variations.

Future features should be evaluated against the project's local-first, understandable, and user-controlled approach.
